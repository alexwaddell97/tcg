# Game sound effects

The editable assignment file is `apps/web/public/sounds/manifest.json`. The replacement guide lives alongside it in `apps/web/public/sounds/README.md`. `/sound-library` is a development-only audition page, also linked from Audio settings, showing the actual assigned files, event names and recommended durations. Music pauses while auditioning and resumes at its previous position afterward.

Ten cues use prepared copies of the user's `public/SE` MP3s, including victory and defeat music. `scripts/prepare-arena-sounds.py` reads `public/sounds/imports.json`, trims source ranges without time-stretching, fades boundaries and balances peak volume to −6 dBFS. It never writes to `public/SE`. Victory (7.2s) and defeat (11.3s) retain their full musical phrases, trimming silence rather than fitting the short card-effect window. Final-score and drawn-match cues use original, dry percussion placeholders from `scripts/generate-arena-sounds.py`; this generator preserves existing WAVs unless passed `--overwrite`.

The runtime loads the public manifest without caching, validates local audio paths, retains defaults for omitted cues and falls back to built-in filenames with a warning on malformed input. Relative paths resolve inside `sounds/`; leading-slash paths resolve against the application's public base, so `/SE/card-draw.mp3` works for nested deployments too. Refreshing the page discards decoded buffers and applies asset changes. Filenames can be WAV or MP3 (also supported: OGG, M4A, AAC, FLAC and WebM, subject to browser decoding).

Web Audio unlocks on a gesture and preloads the small sound set. Effects default to 55%, with independent volume/mute persisted in `tcg-sound-effects`. Voices overlap with a 12-voice limit. Muting, hidden pages, cancelled draws, changing matches and leaving the board cancel pending sounds. Missing/late files and blocked autoplay skip cues without interrupting gameplay. Returning to the tab doesn't replay missed events.

Draw sounds start 250ms apart alongside the animation, including reduced motion. Reveal, ability, turn and score cues follow displayed playback frames. `SoundEffectScope` lets existing recordings finish naturally when the next cue starts, releases completed voices, and cancels unfinished voices only when the board is left or the match changes (audio settings and visibility can still stop the audio bus). Playback stays at the recording's natural speed. Score impacts build through gain, not pitch changes. Match results play only after the finale completes, and reopening the result overlay doesn't repeat the cue.

The first visible score-focus frame acquires a temporary BGM hold. `MusicPlayer` fades a separate mix multiplier to zero over 1500ms and pauses at the current track position. Result audio plays on the existing effects bus; natural completion, mute, cancellation or load failure releases the hold and fades BGM back over 1800ms. Board cleanup also releases it. Holds use ownership tokens so an old result cannot release a newer match's hold. The transient `ducked` flag is not persisted, and neither fade changes the saved volume or mute preference. A direct retreat also acquires a hold when its result appears.

`/board-preview?audio-debug=1` provides safe effect/finale previews, logging `[arena-audio] <cue>` only after an actual source starts. Logging is disabled in production. Tests cover file validity, manifest mapping/fallback, autoplay, cancellation, visibility, mute, late/missing assets and finale order.
